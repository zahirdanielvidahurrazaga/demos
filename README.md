# KaiZen · demos en vivo

Apps reales con datos de ejemplo para que un cliente pruebe cómo trabajaría su negocio.

- **Studio Alma**: reservas para un estudio de pilates (`/demo/alma`).
- **Hoja · cocina fit**: pedidos en línea para recoger, a domicilio o en mesa (`/pedidos/hoja`).

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # → dist/ (Cloudflare Pages: build "npm run build", output "dist")
```

Detalles, base de datos y pendientes en [`CLAUDE.md`](./CLAUDE.md).
